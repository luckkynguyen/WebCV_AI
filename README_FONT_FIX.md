# Fix lỗi hiển thị dấu tiếng Việt

- Đã tăng line-height của tiêu đề trang chủ để dấu tiếng Việt không va chạm với dòng kế tiếp.
- Giữ nguyên bảng màu kem / nâu / vàng champagne.
- Nếu trình duyệt còn hiển thị CSS cũ, nhấn Ctrl + F5 để tải lại.
- Nếu vẫn lỗi sau khi tải lại, hãy kiểm tra font cache/trình duyệt và đảm bảo file được lưu UTF-8.
